# 可爱番茄钟 🍅

一个可爱风格的桌面番茄钟应用，帮助你高效管理时间。

## 功能特点

- 🍅 **番茄钟计时**：支持工作和休息模式切换
- ⏸️ **暂停/继续**：随时控制计时状态
- ⚙️ **自定义时长**：可调整工作和休息时间
- 📊 **统计图表**：可视化展示完成情况和时长分布
- 📔 **日记本**：记录备注和想法
- 🔔 **桌面通知**：时间到达时自动提醒
- 🎨 **可爱界面**：小巧悬浮窗设计，始终置顶

## 安装运行

1. 安装依赖：
```bash
npm install
```

2. 启动应用：
```bash
npm start
```

## 使用说明

### 主界面
- 点击"开始"按钮启动计时
- 点击"暂停"可以暂停/继续计时
- 点击"重置"恢复初始状态
- 可以自定义工作和休息时长（分钟）

### 统计页面
- 查看今日、本周和总计完成的番茄钟数量
- 查看总工作时长
- 最近7天完成情况图表
- 工作时长分布饼图

### 日记本
- 记录每天的想法、备注或心情
- 支持添加、删除日记
- 使用 Ctrl+Enter 快捷保存

## 数据存储

所有数据（统计和日记）保存在本地：
- Windows: `%USERPROFILE%\.cute-pomodoro\`
- macOS/Linux: `~/.cute-pomodoro/`
